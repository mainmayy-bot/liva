# Liva project

- This repository contains the active Liva UI only.
- Application source lives in `src/`; the entry point is `src/main.jsx` and shared styles are in `src/styles.css`.
- Use pnpm for dependency and script commands.
- Run `pnpm build` after UI or behavior changes.
- Do not add generated output, dependency folders, temporary exports, or archived project copies to the repository.
- Preserve the calm, restrained visual language unless the user explicitly requests a redesign.
